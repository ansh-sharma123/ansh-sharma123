> **Multi-disease AI diagnostic platform powered by deep neural ensembles**

[![Repo](https://img.shields.io/badge/View_Repo-181717?style=for-the-badge&logo=github&logoColor=white)](https://github.com/ansh-sharma123/AI-Healthcare-Diagnosis-System)

### 🔐 Wi-Fi Deauthentication Security Tool

> **Network penetration testing tool for authorised security research on Linux**

[![Repo](https://img.shields.io/badge/View_Repo-181717?style=for-the-badge&logo=github&logoColor=white)](https://github.com/ansh-sharma123/cyber-project)
![Shell](https://img.shields.io/badge/Bash_Shell-4EAA25?style=flat-square&logo=gnu-bash&logoColor=white)
![Linux](https://img.shields.io/badge/Linux-FCC624?style=flat-square&logo=linux&logoColor=black)
![Aircrack-ng](https://img.shields.io/badge/Aircrack--ng-CC0000?style=flat-square)

Scans for nearby networks, performs targeted or broadcast deauthentication attacks, and manages wireless adapters — built on `aircrack-ng` tooling.
